# fossilfreerbc-placeholder

Temporary GitHub Pages placeholder for **fossilfreerbc.org** while the real site
(GreenGeeks, theme in `wp-fossilfreerbc`) is offline.

- `index.html` — the page; `404.html` is a copy so every old URL shows it too.
- `CNAME` — `fossilfreerbc.org`.
- `noindex` is set so search engines don't swap the real site's listing for this page.

When the real site is back: point DNS back at GreenGeeks, then archive this repo
or disable Pages.
